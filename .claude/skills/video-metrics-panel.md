# 技术指标数据面板设计说明（Video Metrics Panel）

> 目的：  
> 让用户**直观理解 AI 实际分析了什么、分析质量如何、重点动作在哪里**，提升专业感与信任度。  
> 本面板不承担“教学结论”，而是**分析过程的透明展示层**。

---

## 一、视频基础信息（必备 · 默认展示）

### 🎥 视频元信息
| 指标 | 说明 |
|----|----|
| 视频时长 | 原始视频总秒数 |
| 总帧数 | 视频包含的帧总数 |
| FPS | 帧率（帧 / 秒） |
| 分辨率 | 宽 × 高 |
| 视频格式 | mp4 / mov / avi 等 |

**产品提示建议**  
> 推荐视频：3–12 秒，FPS ≥ 25，分辨率 ≥ 720p

---

## 二、抽帧与分段指标（核心能力展示）

### 🧩 抽帧信息
| 指标 | 说明 |
|----|----|
| 抽帧数量 | 实际用于分析的帧数 |
| 抽帧比例 | 抽帧数 / 总帧数 |
| 抽帧间隔 | 每隔多少帧或毫秒取一帧 |
| 抽帧策略 | 均匀抽帧 / 关键帧 / 动作变化 |

---

### ✂️ 视频分段（动作切分）
| 指标 | 说明 |
|----|----|
| 动作段数 | 视频被拆分的段数 |
| 平均段长 | 每段平均时长 |
| 最长动作段 | 可能为主要问题段 |
| 最短动作段 | 起拍或衔接段 |

**产品表达示例**  
> 主要问题集中在第 2 段（1.2s – 2.4s）

---

## 三、姿态 / 动作识别质量（专业感指标）

> 用于体现“分析是否稳定、是否可靠”

### 🧍 识别稳定性
| 指标 | 说明 |
|----|----|
| 姿态识别成功率 | 成功识别关键点的帧占比 |
| 平均关键点数 | 单帧识别到的关键点数量 |
| 抖动帧比例 | 姿态变化异常的帧比例 |

**简化展示建议**
- 姿态稳定性：⭐⭐⭐⭐☆
- 画面质量：良好 / 一般 / 较差

---

## 四、AI 分析可信度指标（信任构建）

### 🤖 分析质量评估
| 指标 | 说明 |
|----|----|
| 有效分析帧占比 | 实际参与推理的帧比例 |
| 低置信帧数量 | 模型判断不确定的帧 |
| 分析模式 | 单动作 / 连续动作 |

### 📊 综合可信度评分（建议）
| 指标 | 说明 |
|----|----|
| 分析可信度 | 0–100 分（规则或模型计算） |

**示例文案**
> 分析可信度：82 / 100（画面清晰，动作完整）

---

## 五、教学友好型指标（面向普通用户）

> 把“技术指标”翻译成“能不能教”的语言

### 🎯 教学可用性
| 指标 | 说明 |
|----|----|
| 动作完整度 | 是否包含起拍-击球-收拍 |
| 节奏一致性 | 动作是否连贯稳定 |
| 可教学性 | 是否适合给出改进建议 |

**UI 表达示例**
- 动作完整度：✅ 良好  
- 节奏一致性：⚠️ 偏快  
- 可教学性：⭐⭐⭐⭐☆

---

## 六、UI 展示分层建议（强烈推荐）

### Level 1｜默认展示（普通用户）
- 视频时长
- 抽帧数量
- 动作段数
- 分析可信度评分

### Level 2｜展开详情（进阶用户）
- FPS / 分辨率
- 抽帧策略与间隔
- 分段详情
- 姿态稳定性指标

### Level 3｜调试模式（开发 / 高级用户）
- 原始参数
- 帧级统计数据
- 低置信帧列表
- 完整分析 JSON 查看

---

## 七、产品原则总结

- 技术指标 ≠ 炫技  
- 指标存在的唯一目的：  
  **让用户知道 AI 看了什么、看得准不准、哪里最值得关注**

> 技术指标面板是“AI 的体检报告”，  
> 而不是“AI 的考试成绩单”。
